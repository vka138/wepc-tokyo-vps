## 东京机房快在哪，对谁快

东京机房的物理优势是真的，但公开的延迟数字测的不是同一段路，混着看会得出错误结论。

ExtraVM 在自己东京产品页给的一组是机房到周边国家和地区：日本境内 <10ms，韩国 30–40ms，台湾与香港 40–60ms，美西 110–130ms。这是“东京离谁近”。

DMIT 东京的第三方评测给的是另一组，测东京到中国大陆：电信上海约 60–80ms，联通北京 50–65ms，移动广州 50–60ms，同文拿洛杉矶节点 150–180ms 做对比。这是“回国那一段有多长”。

两组数字不能相减，也不能拼成一句话说“东京比洛杉矶快 100ms”。你的用户在日本就看第一组，在大陆就看第二组。

WePC 这台没有公开的延迟实测。2026 年 3 月那篇评测只给了定性描述：三网直连日本后走国际线路进机房，回程电信和移动表现较好，联通绕路、延迟偏高，晚高峰电信表现最差。这个描述和“东京机房”四个字给人的期待有落差。做直播推流这种对上行稳定性敏感的场景，下单前要一个测试 IP 自己跑一遍，晚高峰再跑一遍。

还有一处官网自己的表述冲突：日本卡片的标题写“直播无需中转”，同一张卡片的下单入口名称写的却是“建议中转使用”。这两句话对直播用户是天壤之别，必须问清楚。

## 线路和 IP 的两个坑

### 东京机房不等于 CN2 GIA

JUSTG 在官网 FAQ 里写得直白：东京线路不使用 CN2 GIA，它唯一的 CN2 GIA 机房在莫斯科。DMIT 东京只有 Premium 线三网回程走 CN2 GIA（电信 CN2 GIA、联通 AS9929、移动 CMI），价格更低的 Tier 1 走国际线路，电信联通绕 NTT。

WePC 的日本条目全篇没有 GIA 字样，评测记录的走法也不是全程优化线路。看到“东京”“低延迟”就下单，买到的大概率是国际线路。

### “日本 IP”不等于所有服务都判你是日本人

WePC 这台在评测里的解锁结果是：TikTok 可用（发布与直播推流）、ChatGPT 和 Claude 可用、Steam 货币显示日本，但 Gemini 被判成了美国。

KernelHost 在自家日本页也把话说死了：每个地理位置服务的判定规则不同，无法保证 IP 被判定为某国。所以“日本原生 IP”只说明 IP 注册在日本，不说明每个第三方服务都认。

下单前的确认清单，照这个问，别问泛的：

1. 报具体服务名，一个个问：TikTok 直播、ChatGPT、Claude、Netflix 分别确认，不要问“能不能解锁流媒体”。
2. 要测试 IP 或 looking glass，自己 ping，晚高峰再 ping 一次。
3. 问回程：电信、联通、移动分别怎么走。
4. 问 2TB 双向流量超了以后是停机、限速还是加钱。
5. 问有没有 IPv6（这台评测机型没有）。
6. 问退款窗口的具体条件，以及退到余额的钱能不能提现。

## 常见问题

**东京 VPS 需要备案吗？**
不需要。ICP 备案约束的是中国大陆境内机房的服务器，日本机房的机器不在这套流程里。

**2TB 流量用完了会停机还是限速？**
WePC 的商品页没写超量后的处理方式。同行业两种做法都有：DMIT 的 Premium 线超量直接暂停服务，Tier 1 超量降速继续跑。直播场景尤其要提前问，2TB 双向对持续推流不算宽裕。

**能解锁日区流媒体吗？**
2026 年 3 月那篇评测记录的结果是 TikTok、ChatGPT、Claude 可用，Steam 货币为日本，Gemini 被判成美国。Netflix 和 Disney+ 在那份记录里没有出现，别默认能看。

**能装 Windows 吗？**
WePC 没有公开这台机器的系统模板清单，评测环境是 KVM + BBR 的 Linux。要用 Windows 得先问客服。

**付款和退款怎么走？**
信用卡、PayPal 和支付宝。3 天内且流量不超过 10GB 可以退，超过 10 天不支持退款。
